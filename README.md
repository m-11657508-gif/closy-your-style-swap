# Closy: Your Style Swap

Create an app that allows users to *buy, sell, and swap second-hand outfits, with features that let users **measure their body manually or use AI to estimate their measurements, as well as an **AI stylist that recommends outfits based on the user’s preferences and measurements*. the name of our app is Closy
